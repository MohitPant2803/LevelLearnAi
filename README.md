# LearnLevel AI

LearnLevel AI is an AI-powered personalized learning and skill-development platform that maps and supports learners according to their actual competency levels, rather than just their age or class.

The platform enables educators, volunteers, and mentors to conduct simple diagnostic assessments to understand each learner's current abilities across academics, digital skills, communication, and career readiness. Based on the results, the system maps skill gaps, categorizes learners into appropriate learning levels (L1, L2, L3), and recommends tailored level-wise worksheets and practice activities.

---

## 🌟 Key Features

1. **Interactive Diagnostic Assessment Center**
   - Mapped diagnostic paths for three age groups: Children (5-9), Teenagers (10-14), and Young Adults (15+).
   - Step-by-step quiz wizard that pinpoints specific conceptual gaps.
   - Dynamic scoring engine that outputs custom learning levels (L1-A through L3-C).

2. **Live Educator & Mentor Dashboard**
   - Tracks metrics: total active cohort size, average academics, digital literacy, and communication scores.
   - **Dynamic SVG Visualizations**: Subject Competency Bar Charts, Cohort Distribution Donut Charts, and Longitudinal Cohort Trend Lines.
   - Searchable, category-filtered student records directory.
   - Individual student profiles with history charts and recommended lesson materials.

3. **Curriculum Worksheet Vault**
   - Mapped level-wise printable worksheets.
   - Modern horizontal filter chips for fast subject sorting.
   - Full checklists and slide-in preview modals.

4. **Cozy Dual-Theme Aesthetic**
   - Features a clean, organic Scandinavian-inspired **Warm Spruce & Sand** design.
   - Seamless Light/Dark theme switch with automatic dynamic SVG chart recoloring.
   - Zero-lag optimized animations and responsive layouts (mobile scrollable navigation bar, vertical stacking inputs, and layout wrappers).

---

## 🛠️ Technology Stack

- **Core**: HTML5 (Semantic Structure)
- **Style**: Custom Vanilla CSS3 (variables/custom properties, responsive grid & flexbox, custom transitions)
- **Logic**: Vanilla ES6 JavaScript (routing, theme managers, dynamic inline SVG renderers, event registers)
- **Fonts**: Nunito (body text) and Outfit (headings) via Google Fonts

## 🚀 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/MohitPant2803/LevelLearnAi.git
   ```
2. Open the directory:
   ```bash
   cd LevelLearnAi
   ```
3. Run a local development server. For example, using Python:
   ```bash
   python -m http.server 8000
   ```
4. Open your browser and navigate to:
   ```
   http://localhost:8000
   ```
